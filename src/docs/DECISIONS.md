| 2026-11-02 | Passage v1 → v2 | **Réécriture complète autour des fiches.** L'humain ne produit plus de cours bruts mais des sets de fiches numérotées (≤ 1 page, thèse + étiquettes, skill « fiches-revision-droit »), et a cessé d'utiliser la v1 : le dialogue Feynman était trop long, ses questions mauvaises, et l'utilité ne justifiait pas le coût (« 30 minutes pour expliquer quelque chose qui n'en demandait pas une »). Décisions prises avec l'humain : (1) une fiche = une carte FSRS ; (2) le sectionnement LLM, les rubriques LLM, leur validation, l'importance 1-5, le tri, le versionnage par chapitre et l'appariement de sections disparaissent — la structure de la fiche sert de barème, calculé en code ; (3) le Feynman (chat, transcription, TTS, bilan) disparaît sans remplaçant ; son apport utile (« dire pourquoi » vs « réciter ») est repris par une note « raisonnement » sur les points Cause/Conséquence/Logique ; (4) cycle unique : nouvelle fiche = lecture → puzzle 30 s → blurting → correction ; révision = blurting à froid directement ; si insuffisant : relecture → puzzle → 2ᵉ blurting → correction ; puis auto-note ; (5) le verdict LLM met en avant un bouton, l'utilisateur choisit ; (6) après relecture, la note est limitée à Again/Hard (le rappel à froid a échoué, la 2ᵉ passe ne mesure pas la mémoire) ; (7) unité = fiche entière, les fiches de synthèse sont planifiées comme les autres (réversible).
